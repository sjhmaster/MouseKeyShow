## English

**MouseKeyShow** is a lightweight, high-performance desktop utility designed for live streamers, course creators, and presenters to visualize real-time keyboard strokes and mouse actions on Windows.

> **Note**: This repository provides official pre-built binary distributions. Source code is proprietary.

### ✨ Key Features
* **Native C++ Engine**: Ultra-low latency and minimal resource consumption.
* **Keystroke & Mouse Visualizer**: Smooth, real-time overlay showing keyboard combinations and mouse clicks.
* **Dynamic Cursor Sizing**: Transparently adjust Windows system mouse cursor scale (Level 1-15).
* **WYSIWYG Mini-Map**: Drag-and-drop mini-map inside the configuration panel for exact screen placement.
* **Theme Customization**: Built-in support for dark themes, transparency adjustments, and scale tuning.

### 📥 Download & Installation
1. Go to the [**Releases**](../../releases) page.
2. Download the latest `MouseKeyShow.rar`.
3. Extract the `.rar` archive to your preferred local folder.
4. Run `MouseKeyShow.exe` (Run as Administrator is recommended for full-screen game overlays).

### ⚙️ System Requirements
* **OS**: Windows 10 / Windows 11 (64-bit)
* **Architecture**: x86_64

**MouseKeyShow** 是一款基于 C++ 构建的高性能 Windows 屏幕键鼠实时可视化工具，专为录屏教学、游戏直播及演示场景设计。

> **说明**：本仓库仅作为官方二进制打包版本的发布渠道，本项目非开源软件。

### ✨ 核心功能
* **C++ 原生性能**：极速响应，极低 CPU 及内存占用。
* **按键与鼠标实时显示**：平滑捕获并高亮显示键盘按键组合、左右键及滚轮点击动作。
* **光标大小动态调节**：支持无感调节 Windows 系统鼠标指针的物理显示大小（1-15 级）。
